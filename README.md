# @brand-map/postgres: Zero-Abstraction Postgres for TypeScript

`@brand-map/postgres` aims to make Postgres and TypeScript work beautifully together. No abstractions, no distractions: just your database, with type safety.

### »&nbsp; [Go to documentation](https://brand-map.dev/docs/postgres)

## Quick Start (Bun)

```bash
bun add @brand-map/postgres
```

Create `brand-map-postgres.config.json`, then generate types:

```bash
bunx @brand-map/postgres
```

This project is a fork of [Zapatos](https://github.com/jawj/zapatos).

Runtime query execution supports both `pg` and Bun SQL clients.

- `@brand-map/postgres/pg`
- `@brand-map/postgres/bun`
- `@brand-map/postgres/shared`
- `@brand-map/postgres/types`
